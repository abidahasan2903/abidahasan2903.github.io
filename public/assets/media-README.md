# Portfolio media assets

Add the supplied images here to replace the built-in visual fallbacks:

- `public/assets/abid-profile.jpg` — profile portrait; displayed in a round frame.
- `public/assets/studora-logo.png` — the S-like STUDORA app mark.
- `public/assets/calcora-logo.png` — the CALCORA calculator icon.

Project images use `object-fit: contain` to preserve their full image without distortion. The profile portrait uses a circular crop. JPG, PNG, or WebP can be used by updating the corresponding filename in `src/App.tsx`.
